このページは、オーナー、AM、PM、FM、BMの**標準的な業務構造そのもの**ではなく、案件条件によって責任分担がどう変わるかを扱います。

標準構造、業務領域、KPI・KRI、意思決定、BM接続を先に確認する場合は[所有・運営・維持管理の業務構造](../../management-structure/)を参照してください。

## 変動させる主な条件

| 条件 | 変わり得ること |
|---|---|
| 投資用・賃貸不動産 | オーナー → AM → PM → BMが明確になり、テナント側FMが契約境界を挟んで並立する |
| AMを置かない賃貸不動産 | PMが予算案・投資案・資産報告の一部を担い、オーナーへ直接上申する |
| 自社所有・自社利用 | オーナー・経営 → FM → BMが中心となり、独立したPMが存在しない場合がある |
| オーナー直接委託 | オーナー側に運営影響評価、発注・検収、法令・緊急判断の受け皿が必要になる |
| 一組織が複数機能を兼務 | 起案と承認、技術評価と費用査定、実施と検収を機能別に分ける必要がある |
| 再委託 | 元請けの統括、再委託先の専門実施、法的義務、費用負担を別に確認する |

## 責任分界で確認する項目

- 契約に基づく提供責任
- 業務上の統括・実行責任
- 社内の決裁・発注権限
- 技術評価責任
- 法令上の義務主体、資格者、行政報告名義
- 費用負担
- 緊急停止、利用再開、残存リスク受容
- 台帳・証跡の正本保有

## 同じ会社でも機能を分ける

一つの法人又は部署がAM・PM、PM・FM、PM・BM等を兼ねる場合でも、自己検収や利益相反を避けるため、起案者と承認者、実施者と確認・検収者、予算執行者と残存リスク受容者を記録上区別します。

具体的な判断の流れは[意思決定と責任分界](../../management-structure/connections/decision-and-responsibility/)、代表例は[3件のシナリオ](../../management-structure/scenarios/)で確認できます。

最終的な分担は、契約書、仕様書、賃貸借契約、管理規約、権限規程、法令、条例、行政運用を優先します。
