アセットマネジメント（AM）は、オーナー又は投資家から委任を受け、投資方針を資産・ポートフォリオの運用計画へ展開する機能です。建物の技術状態を直接診断するのではなく、技術情報を投資・資産運用の判断へ変換します。

## 中心となる問い

- 保有期間と投資目標に対して、いつ、いくら投資するか
- OPEXとCAPEXをどの年度・資産へ配分するか
- 修理、更新、繰延、売却のどれが資産価値とキャッシュフローに適合するか
- PM等の委任先が目標・権限・報告要件を満たしているか
- 災害、法令、環境、集中リスクをポートフォリオでどう管理するか

| AM-03 | 資産収益・キャッシュフロー管理 |
| AM-04 | OPEX・CAPEX配分管理 |
| AM-05 | 資産価値・投資効果評価 |
| AM-06 | PM等の選定・統制・評価 |

| AM-08 | 売却・出口戦略管理 |

## BMとの接続

AMはPMを介する間接接続が多い一方、OPEX・CAPEX配分、取得DD、重大更新、ポートフォリオリスクではBM情報を直接判断材料にします。

| BMから受け取る情報 | AMでの利用 |
|---|---|
| 劣化状態、故障履歴、更新需要 | AM-04、AM-05、AM-07の投資・リスク評価 |
| 修繕費、追加作業、実績 | AM-03、AM-04の収益・予算管理 |
| 法定不適合、重大事故、停止リスク | AM-07のポートフォリオ・リスク管理 |
| 設備台帳、図面、履歴 | AM-02の取得DD、AM-08の出口判断 |

投資判断の流れは[意思決定と責任分界](../../connections/decision-and-responsibility/)で確認できます。
