プロパティマネジメント（PM）は、個別不動産の収益向上と契約履行を目的に、賃貸運営、物件収支、テナント及びBM等の委託先を統括する機能です。

## 中心となる問い

- 物件の稼働、賃料、NOIをどう維持・改善するか
- テナントへの影響を抑えながら工事・停止をどう調整するか
- 物件予算、契約範囲、追加費用をどう管理するか
- BM・専門業者をどう選定、発注、監督、検収するか
- 物件の実績・リスクをAM又はオーナーへどう報告するか

## 業務領域

| ID | 業務領域 |
|---|---|
| PM-01 | リーシング・稼働管理 |
| PM-02 | 賃貸借契約・賃料管理 |
| PM-03 | テナントリレーション・入退去管理 |
| PM-04 | 物件収支・予算管理 |
| PM-05 | 物件運営・サービス水準管理 |
| PM-06 | BM・専門業者の調達・契約・評価 |
| PM-07 | 修繕・設備更新・工事統括 |
| PM-08 | 物件情報・報告・リスク管理 |

## 主に見るKPI・KRI

FIN-01（物件NOI）、FIN-04（物件OPEX予算差異率）、OPS-01〜OPS-04（稼働・賃貸運営）、OPS-09（委託先契約履行）、USR-01（テナント満足）、RSK-01（法定・契約上の未実施／不適合）を中心に見ます。

## BMとの接続

PMは、BMの受託範囲、作業条件、予算、発注、テナント調整、検収へ直接関与しやすい機能です。

- 要求・制約：PM-05 → BM-02、BM-04、BM-06〜BM-13
- 調達・評価：PM-06 → BM-01、BM-02、BM-05、BM-13、BM-17
- 修繕・更新：PM-07 → BM-09、BM-10、BM-14
- 報告・リスク：BM-13、BM-14、BM-17、BM-18 → PM-08

ただし、BMが技術的に必要と評価したこと、PMが発注・検収できること、オーナー又はAMが投資を承認することは別の責任です。
