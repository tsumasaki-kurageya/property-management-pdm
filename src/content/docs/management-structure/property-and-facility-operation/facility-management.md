ファシリティマネジメント（FM）は、企業・団体等の組織活動のため、施設とその環境を経営戦略的に企画、管理、活用し、利用価値と施設関連資源を最適化する機能です。単なる設備保守又は総務庶務の別名ではありません。

## 中心となる問い

- 事業活動に必要な施設性能とサービス水準は何か
- 重要区画、利用時間、停止可能時間、代替手段をどう定めるか
- 施設群、拠点、スペースをどう配置・利用するか
- 保全・更新の優先順位を、事業影響とライフサイクルでどう決めるか
- BCP、安全、環境、総施設コストをどう管理するか

## 業務領域

| ID | 業務領域 |
|---|---|
| FM-01 | FM戦略・ガバナンス |
| FM-02 | 施設需要・拠点ポートフォリオ管理 |
| FM-03 | スペース・ワークプレイス管理 |
| FM-04 | 利用者サービス・体験管理 |
| FM-05 | 施設性能・保全・更新方針 |
| FM-06 | ファシリティ総コスト・調達管理 |
| FM-07 | BCP・安全・セキュリティ・リスク管理 |
| FM-08 | 環境・脱炭素・ライフサイクル管理 |

## 主に見るKPI・KRI

FIN-06（ファシリティ総コスト）、OPS-08（施設・スペース利用率）、USR-02〜USR-05（利用者価値・事業影響）、QTY-05（エネルギー原単位・削減率）、RSK-04（重要設備・サービス停止リスク）、RSK-06（環境目標乖離）、RSK-07（BCP訓練・復旧目標達成度）を中心に見ます。

## BMとの接続

FMは、利用条件と施設性能をBMのサービス仕様、運転条件、保全・更新、災害対応へ渡します。

| FM領域 | 主に接続するBM領域 |
|---|---|
| FM-04 | BM-06、BM-07、BM-11、BM-12、BM-13 |
| FM-05 | BM-08、BM-09、BM-10、BM-14 |
| FM-06 | BM-01、BM-02、BM-15、BM-16 |
| FM-07 | BM-03、BM-04、BM-05、BM-08〜BM-11、BM-17 |
| FM-08 | BM-07、BM-08、BM-10、BM-14、BM-18 |

賃貸ビルでは、FMの要求が貸主側PMとの契約・調整を経てBMへ届く場合があります。自社利用施設では、FMがBMを直接契約し、発注・検収機能も担う場合があります。
