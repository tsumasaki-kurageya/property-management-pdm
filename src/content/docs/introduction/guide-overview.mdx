このガイドラインは、建物管理業務を一冊の文書として順番に読むものではありません。**知りたいことに応じて、全体像・業務索引・プロセス・条件差・詳細資料を使い分けるための業務知識基盤**です。

## このページで分かること

- ガイドラインを構成する情報群の役割
- 業務カタログ、業務プロセス、条件差、現場作業手順の使い分け
- 自分の問いに対して、どのページから読み始めるべきか

## 情報群の役割

<CardGrid>
  <Card title="全体像を理解する" icon="open-book">
    「建物管理は誰が、何を目的に行うのか」に答えます。まず[所有・運営・維持管理の業務構造](../../management-structure/)と[関係者と役割](../people-and-roles/)を確認します。
  </Card>
  <Card title="特定業務を探す" icon="magnifier">
    「この作業や課題は、どの業務に該当するか」に答えます。[18の業務領域](../../overview/)で大分類を把握し、[業務カタログ](../../reference/business-catalog/)を辞書・索引として使います。
  </Card>
  <Card title="流れ・関係を理解する" icon="right-arrow">
    「この業務の前後に何があり、どこへ結果が渡るか」に答えます。[標準業務ライフサイクル](../../overview/business-lifecycle/)と[12横断プロセス](../../reference/processes/)を使います。
  </Card>
  <Card title="条件による違いを理解する" icon="seti:config">
    「建物用途、管理方式、契約階層、責任主体によって何が変わるか」に答えます。[条件による違い](../../variations/)から対象条件へ進みます。
  </Card>
  <Card title="個別業務を詳しく理解する" icon="tools">
    「現場では何を、どの順序で行うか」に答えます。清掃、設備、警備等の[現場の業務](../../field-work/)と[現場作業手順](../../reference/field-procedures/)を使います。
  </Card>
  <Card title="分析・製品企画に活用する" icon="star">
    「課題がどの業務・責任・情報接続に関係するか」を整理します。業務IDとプロセスを共通言語として、課題分析や製品カバレッジ検討へ接続します。
  </Card>
</CardGrid>

## 資料の使い分け

| 情報 | 主な問い | 読み方 |
|---|---|---|
| 業務構造 | 誰が、何を目的に、どのレイヤーで判断・実行するか | 全体像を順に読む |
| 18の業務領域 | ビルメンテナンス業務にはどのような大分類があるか | 俯瞰図として見る |
| 業務カタログ | 特定の作業・判断・管理行為はどの業務IDか | **先頭から読まず、辞書・索引として検索する** |
| 標準業務ライフサイクル | 契約から計画、実施、報告、請求、改善までどう進むか | 大きな流れを確認する |
| 12横断プロセス | 個別業務の前工程・後工程・分岐・接続は何か | 業務IDを特定してからたどる |
| 条件差資料 | 建物用途、常駐・巡回、元請け・再委託等で何が変わるか | 対象業務を特定した後に比較する |
| 現場業務・作業手順 | 清掃、設備、警備等で現場が何をするか | 必要な業務領域だけ詳しく読む |

:::tip[業務カタログの位置付け]
業務カタログは、175業務を最初から順番に学ぶための本文ではありません。自然言語の課題や作業名から業務IDを特定し、業務領域・プロセス・詳細資料へ進むための辞書・索引です。
:::
