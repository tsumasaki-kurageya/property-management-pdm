## 1. 全体像を知る

**対象読者:** 新規参加者、業務知識の少ない開発メンバー  
**分かること:** 建物管理全体の構造と、ビルメンテナンス会社の位置付け

## 2. 特定の業務を探す

**対象読者:** 具体的な業務課題、作業名、問い合わせを起点に調べる人  
**分かること:** 対象業務の業務ID、所属領域、前工程・後工程、関連業務

1. [業務エクスプローラー](/explorer/)または[業務カタログ](../reference/business-catalog/)でキーワードを探す
2. 業務IDを特定する
3. [18の業務領域](../overview/)で所属領域を確認する
4. [12横断プロセス](../reference/processes/)で前工程・後工程を確認する
5. 必要に応じて関連領域や詳細資料へ進む

:::tip[業務カタログは辞書・索引です]
175業務を先頭から読むのではなく、作業名や動詞から業務IDを特定するために検索してください。
:::

具体例を使った探索方法は、[業務ガイドラインの使い方](./how-to-use/)で説明しています。

## 3. 業務の違い・詳細を調べる

**対象読者:** 対象業務を特定済みで、適用条件や現場詳細を確認したい人  
**分かること:** 条件による差、責任分界、法定業務、現場作業手順

1. 対象の業務IDと業務領域を確認する
2. [条件による違い](../variations/)で差分の観点を選ぶ
3. 建物用途、常駐・巡回、元請け・再委託、責任分界、法令の該当ページを読む
4. 清掃、設備、警備等の[現場の業務](../field-work/)を確認する
5. 必要に応じて[現場作業手順](../reference/field-procedures/)へ進む

## 迷ったときの選び方

| 知りたいこと | 最初に開くページ |
|---|---|
| 建物管理全体を理解したい | [ガイドライン全体像](./guide-overview/) |
| 作業名から業務を探したい | [業務ガイドラインの使い方](./how-to-use/) |
| 業務IDを直接検索したい | [業務カタログ](../reference/business-catalog/) |
| 前後工程を知りたい | [12横断プロセス](../reference/processes/) |
| 条件による違いを知りたい | [条件による違い](../variations/) |
| 現場作業を詳しく知りたい | [現場の業務](../field-work/) |

:::caution[標準モデルとして利用してください]
実際の責任、資格、作業方法、報告先は、建物、契約、地域、設備、時間帯等によって変わります。
:::
